# X Bulk Scheduler — functionality test matrix

This file tracks whether the things the tool is meant to do have actually been tested, and what remains. The individual issues and current progress are in [ISSUE-QUEUE.md](ISSUE-QUEUE.md). Contributors: comment on an open `help wanted` issue to volunteer or discuss a test before starting; assignment is controlled by repository permissions. Use fictional data or your own authorized test account. Never publish private posts, queues, account identifiers, credentials or cookies.

## How to read this

- ✅ means passed only at the level stated; ✔️ means partial; ❌ means not demonstrated or known failure; ❎ means blocked.
- **Earlier X** refers to a prior custom test extension, not the current public main or latest build. **Source/mock** means simulated local tests, not an X or deployed test. **Unknown** does not mean failed.
- Public main observed at `68568909a15a1c6b69cebd6335751995e83fa9dd` before this documentation update; application source is the older public version. Experimental `0.13.1-test.10` is separate, preview-only and was not installed or deployed. The user's deployed revision is unknown. Experimental test files and private captures are not currently in public main; do not assume local commands below run from this repository.
- Each future session: record version, date, environment, exact procedure or command, pass/fail/skip and evidence. Link new bugs to the issue queue. Never mark a feature complete from a mock or a demo alone.
